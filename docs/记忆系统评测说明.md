# 记忆系统评测说明

## 目标

`/memory` 用于隔离验证记忆是否提升多人角色对话。左侧为无记忆基线，右侧为记忆系统；同一轮会随机一次角色名单，两侧使用同一 Builder、模型采样参数、玩家输入和短期历史长度。唯一变量是右侧额外注入会话记忆。

## 两个实验条件

| 条件 | 注入内容 |
| --- | --- |
| 无记忆基线 | 最近 N 条对话（N 可配置） |
| 记忆系统 | 同一最近 N 条对话 + 公共结构化记忆 + 关键词 RAG 命中的自定义记忆 |

两个条件的消息记录从第一轮开始分开保存，避免右侧 AI 回复反向影响左侧历史。

## 记忆机制

- 短期历史：左右共用相同、可配置的最近消息窗口。
- 公共记忆：角色状态（目标、位置、外观、健康、态度）、世界状态（设定、时间、天气、地点）、事件链、关键物品。
- 事件压缩：最多 5 条，溢出时合并最旧两条为“前情”。
- 物品淘汰：最多 5 件，按最近出现轮次保留。
- 手工记忆：人工添加、可停用或删除，永不被模型自动改写。
- 自动记忆槽位：人工定义标题与关键词，模型仅在新增对话与关键词明确相关时更新已有槽位，不能自行新增。
- RAG：当前采用可复现的关键词/字符二元组检索，按相关度取 Top K（可配置）。接口与 UI 已与向量检索解耦，后续可替换为 embedding 检索。
- 异步更新：默认每 10 个玩家轮次更新一次，当前对话生成完成后后台更新，不阻塞下一轮；也可以手动“更新”。

记忆仅存在于当前评测会话。重启实验会同时清空右侧记忆和两侧上下文。

## 建议测试集

1. 延迟事实回忆：第 1 轮给出名称、地点或约定，第 10 轮后追问。
2. 冲突更新：先说“钥匙在桌上”，后说“钥匙被小明带走”，检查是否采用最新明确事实。
3. 删除与遗忘：删除手工记忆后，检查后续注入不再出现该记忆。
4. 多角色归属：让不同角色分别持有不同信息，检查是否串人设或串事实。
5. 无关记忆干扰：加入不相关自定义记忆，检查本轮不应命中或影响剧情。
6. 事件压缩与物品淘汰：连续引入 6 个事件、6 件物品，检查上限规则。
7. 自动槽位：设置关键词，分别发送相关和无关消息，检查仅相关消息改写该槽位。

## 指标

| 指标 | 含义 |
| --- | --- |
| 延迟回忆准确率 | 长间隔后能正确回忆的明确事实比例 |
| 过时事实率 | 已被新事实覆盖后仍引用旧事实的比例 |
| 幻觉记忆率 | 输出未在对话或手工记忆中出现的事实比例 |
| 冲突消解准确率 | 面对事实更新时采用最新事实的比例 |
| 检索准确率 | Top K 中与当前输入相关的记忆比例 |
| 更新成功率 | 异步更新返回合法结构化记忆的比例 |
| 角色泄漏率 | 将一个角色的事实/动机错误归属给另一角色的比例 |
| 额外成本 | 记忆条件相较基线的输入 token 和响应耗时变化 |

结论必须以同一组玩家输入下左右记录的统计结果为准，不应仅凭单轮文风判断记忆效果。
