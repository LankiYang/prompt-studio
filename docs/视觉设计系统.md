# Prompt Studio 视觉设计系统

版本：1.0  
适用范围：团队工作区、Prompt 调试器、多人聊天房、记忆评测和房间配置

## 品牌标识

品牌图形由 Prompt 箭头、输入光标和状态点组成。深青色代表稳定的团队工作流，珊瑚色光标代表持续迭代，琥珀色状态点用于强调实验与洞察。

- 浏览器图标：`public/favicon.svg`
- React 组件：`src/components/BrandMark.tsx`
- 产品名称：`Prompt Studio`

图标应保持正方形比例，不添加文字、不改变内部颜色，也不放在相近深度的青色背景上。

## 基础令牌

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 主操作 | `#0b6b61` | 创建、保存、运行和当前导航 |
| 主操作悬停 | `#08574f` | 主按钮 Hover |
| 主操作浅底 | `#e9f5f2` | 选中项和轻提示 |
| 对比强调 | `#e46f51` | 对照侧、差异和品牌光标 |
| 实验强调 | `#f5c76b` | 实验状态和品牌状态点 |
| 页面背景 | `#f4f6f5` | 工作区背景 |
| 主文本 | `#172522` | 标题和主要信息 |
| 次文本 | `#62706c` | 描述、元数据和辅助信息 |
| 边框 | `#d9e1de` | 卡片、输入框和分隔线 |

语义色保留蓝、青、琥珀和珊瑚，用于多模型、多版本和状态对比，不把整页染成单一色系。

## 组件规则

- 页面只使用一层主内容容器，卡片不嵌套卡片。
- 卡片圆角为 `8px`，按钮和输入框圆角为 `6px`。
- 主按钮使用深青底白字；次按钮使用白底中性边框；危险操作使用珊瑚红。
- 图标按钮必须提供 `title` 或可访问名称。
- 表单聚焦使用青色边框和三像素半透明焦点环。
- 固定工具栏和左右对比栏必须设置稳定尺寸，内容变化不能推动整体布局。
- 小于 `820px` 时工作区侧栏改为抽屉；小于 `700px` 时聊天室工具栏改为横向可滚动操作区。

## 页面结构

- Studio：浅色侧栏、固定顶栏、最大 `1380px` 内容区。
- Prompt 调试器：左右两侧保持等宽，珊瑚色代表左侧，青色代表右侧。
- 聊天室：顶部品牌与连接状态固定，操作区在窄屏横向滚动，消息区独立滚动。
- 登录和加入房间：单一任务面板，不使用营销式 Hero 或装饰性背景。

## 可访问性

- 正文与背景对比度不低于 WCAG AA。
- 键盘焦点始终可见，不能只依赖颜色表达状态。
- 窄屏下按钮文字不截断；次要工具允许横向滚动，不允许覆盖主内容。
- 动画只用于轻量状态反馈，不改变组件尺寸。
