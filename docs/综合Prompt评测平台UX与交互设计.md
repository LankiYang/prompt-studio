# 综合 Prompt 评测平台 UX 与交互设计

## 23. 全域资源管理体验

平台不是只有 Prompt 编辑器和评测结果页。工作空间内的项目、Prompt、角色、世界观、测试集、评分卡、模型配置、调度方案、记忆方案、报告和成员都使用统一的资源管理框架。

### 23.1 标准资源列表页

页面结构：

1. 页面标题、资源数量和主要“新建”按钮。
2. 搜索、筛选、排序、保存视图和导入。
3. 数据表格或适合该资源的密集列表。
4. 批量操作栏。
5. 分页和每页数量。

每个资源列表至少支持：

- 关键词搜索。
- 状态筛选：使用中、草稿、已归档、已删除等。
- 负责人和创建人筛选。
- 创建时间和更新时间筛选。
- 按更新时间、名称和使用次数排序。
- 自定义显示列。
- 将筛选保存为个人视图。
- 复制当前筛选链接。
- 导出当前查询结果。

列表行操作：

- 打开详情。
- 编辑。
- 复制。
- 查看引用。
- 归档或恢复。
- 移入回收站。
- 更多操作。

不把高风险删除按钮直接放在列表主操作区。

列表边界：

- 加载时使用稳定骨架，不让列宽跳动。
- 空列表区分“尚未创建”和“筛选无结果”。
- 筛选无结果提供清除筛选，不重复提示创建资源。
- 分页切换保留筛选、排序和列设置。
- 删除当前页最后一条后自动回到有效页码。
- 部分字段无权限时隐藏字段，不显示伪造的空值。
- 大列表使用服务端分页，不一次加载全部资源。

### 23.2 标准新建入口

每种可创建资源提供：

- 空白创建。
- 从模板创建。
- 复制已有资源。
- 从文件导入。

新建流程要求：

- 首屏只展示必要字段。
- 高级字段折叠。
- 名称重复时提示，但仅在业务唯一时阻断。
- 实时保存本地表单草稿。
- 关闭后可恢复未提交内容。
- 创建成功后进入详情页，而不是停留在空表单。
- 创建失败保留全部输入并定位到错误字段。
- 重复点击使用幂等处理。

### 23.3 标准资源详情页

所有业务资源详情页遵循相同布局：

- 顶部：名称、状态、负责人、更新时间和主要操作。
- 概览：核心字段和当前使用状态。
- 版本：版本历史、Diff 和创建新版本。
- 引用：被哪些项目、评测、运行、报告和发布使用。
- 活动：创建、编辑、归档、恢复和权限变更。
- 评论：协作讨论和解决状态。
- 权限：谁可以查看、编辑、删除和发布。

右上角操作顺序：

1. 与当前任务最相关的主操作。
2. 编辑或创建新版本。
3. 复制。
4. 更多菜单中的归档、删除和管理权限。

### 23.4 标准编辑体验

可变资源：

- 允许原地编辑。
- 保存时验证版本号或 `updatedAt`。
- 其他成员已修改时显示字段级 Diff。
- 用户可以合并、覆盖为新副本或取消。

版本化资产：

- 当前已保存版本只读。
- 点击编辑时创建或打开草稿。
- 保存草稿不改变生产和历史运行。
- “保存新版本”生成不可变快照。

不可变证据：

- 不显示编辑入口。
- 允许追加标签、评论、人工判断和重试记录。
- 所有人工修订显示原值与修订值。

离开保护：

- 自动保存成功不弹无意义确认。
- 自动保存失败时阻止静默离开。
- 表单包含未上传文件时明确提示。
- 浏览器刷新后恢复最近草稿，并告知恢复时间。

### 23.5 归档、回收站和永久删除

三个动作必须分开：

| 动作 | 用户理解 | 是否可恢复 | 默认可见性 |
| --- | --- | --- | --- |
| 归档 | 暂时不再使用 | 是 | 默认列表隐藏，可筛选 |
| 移入回收站 | 计划删除 | 保留期内可恢复 | 仅回收站可见 |
| 永久删除 | 不可恢复地清理 | 否 | 不再可见，仅留审计摘要 |

归档：

- 通常不要求输入名称确认。
- 显示该资源当前是否仍被生产或运行使用。
- 生产引用中的资源不能直接归档，需先替换引用。

移入回收站：

- 确认弹窗展示资源名称、版本数、引用数和保留期限。
- 有不可变引用时说明“运行快照不会被删除”。
- 操作后提供短时撤销。

恢复：

- 恢复前检查父项目、名称冲突和依赖状态。
- 父项目也在回收站时，可选择一起恢复。
- 同名资源已存在时允许改名恢复或恢复为独立副本。

永久删除：

- 仅管理员可用。
- 输入资源名称确认。
- 展示完整依赖图和不可删除项。
- 不允许通过级联删除破坏运行、报告、评分和发布证据。
- 大规模删除创建后台任务，可查看进度和失败项。

### 23.6 引用与依赖查看

每个资源详情页提供“引用”标签，显示：

- 当前被谁使用。
- 使用的是资源本身还是具体版本。
- 是否属于生产快照。
- 删除、归档或修改会影响什么。

依赖按层级展示：

```text
Prompt
  → Prompt 版本
    → 评测运行
      → 模型调用
      → AI / 人工评分
      → 报告
    → 发布记录
```

依赖操作：

- 点击跳转到引用对象。
- 按生产、历史和草稿筛选。
- 导出依赖清单。
- 在删除前自动生成影响摘要。

### 23.7 批量操作

批量选择后显示固定操作栏，包含：

- 添加标签。
- 更改负责人。
- 归档。
- 恢复。
- 移入回收站。
- 导出。

执行前展示：

- 已选择数量。
- 有权限数量。
- 将执行数量。
- 因生产引用、权限或状态被跳过的数量。

执行后生成结果清单，不使用一句“部分失败”结束。

禁止批量执行：

- 发布。
- 永久删除生产相关资源。
- 覆盖 Prompt 正文。
- 修改运行结果。
- 修改已提交评分。

### 23.8 回收站

回收站支持按资源类型、删除人和到期时间筛选。

每行显示：

- 资源名称和类型。
- 原所属项目。
- 删除人和删除时间。
- 剩余保留时间。
- 依赖状态。
- 恢复和永久删除操作。

到期清理：

- 到期前通知资源负责人。
- 生产和审计引用存在时只清理可变资源内容，不清理证据快照。
- 清理失败进入管理员任务队列。

## 24. 各业务模块的管理操作

### 24.1 工作空间

列表与切换：

- 用户有多个工作空间时支持切换。
- 显示成员数、项目数、用量和状态。

可修改：

- 名称、Logo、默认时区、默认模型、预算、数据保留策略。

删除：

- 只能由所有者发起。
- 必须先处理未完成运行、生产发布和最后一名所有者。
- 进入延迟删除状态，期间可取消。

### 24.2 项目

新增：

- 空白项目。
- 从项目模板。
- 复制项目结构。
- 导入旧项目。

修改：

- 名称、描述、负责人、成员、默认资源和归档状态。

复制：

- 默认只复制配置和资产引用。
- 可选择复制测试集、报告模板和权限。
- 不复制运行结果、原始数据和发布历史。

删除：

- 显示包含的 Prompt、测试集、运行、报告和数据量。
- 可选择先导出。
- 进入项目回收站。

### 24.3 Prompt

新增：

- 空白 Prompt。
- 从模板。
- 复制现有 Prompt。
- 导入文本或 JSON。

查询：

- 名称、内容全文、变量、标签、负责人、生产状态和最近分差。

修改：

- Prompt 元数据允许原地修改。
- Prompt 正文通过草稿和新版本修改。

删除：

- 未被引用的 Prompt 可移入回收站。
- 有运行或报告引用时，资产可隐藏，但版本快照继续存在。
- 当前生产 Prompt 必须先发布替代版本。
- 永久删除前显示所有版本和引用。

### 24.4 变量与上下文方案

变量操作：

- 新增单个变量。
- 批量导入变量定义。
- 修改类型、说明、示例和校验规则。
- 查看在哪些 Prompt 中使用。
- 重命名时批量生成引用迁移预览。
- 未使用变量可删除；已使用变量只能弃用。

上下文方案：

- 新建和复制。
- 编辑历史窗口、注入顺序、截断和格式。
- 保存版本。
- 查看模拟上下文和 Token 估算。
- 归档旧方案。

### 24.5 角色与角色集

角色：

- 新增、复制、批量导入。
- 编辑人设、能力、关系、视觉资料和标签。
- 归档和恢复。
- 查看参与的角色集、测试集和运行。

角色集：

- 新建、复制。
- 添加、移除、排序角色。
- 设置在场状态和默认发言权重。
- 保存版本。
- 使用成员 Diff 查看两版变化。

边界：

- 重名角色允许，但选择器同时显示角色 ID 或来源项目。
- 删除角色不影响历史运行。
- 已归档角色默认不出现在新运行选择器。

### 24.6 世界观

- 新建、复制、导入。
- 编辑背景、地点、规则、禁用设定和时间线。
- 保存版本和查看文本 Diff。
- 查看哪些 Prompt、测试集和运行引用。
- 归档、恢复和回收站。

边界：

- 修改世界观不自动改变正在运行的评测。
- 删除地点或规则前显示测试案例引用。
- 大文本支持章节导航和全文搜索。

### 24.7 模型连接与模型配置

模型连接：

- 新增 Provider 连接。
- 测试连接。
- 更新 Key 和 Base URL。
- 停用、启用和删除。
- 查看最近成功率和错误。

模型配置：

- 新增、复制预设。
- 编辑模型、温度、惩罚项、长度、超时和重试。
- 保存版本。
- 归档和恢复。

边界：

- Key 永不回显。
- 更新 Key 要求重新输入，不支持读取旧 Key。
- 停用连接不终止已发出的调用。
- 删除连接不删除历史模型快照。

### 24.8 调度与记忆方案

调度方案：

- 新建、复制、编辑和版本化。
- 可视化预览用户线、@ 线和主动线。
- 模拟角色抽取。
- 归档和恢复。

记忆方案：

- 新建、复制、编辑和版本化。
- 管理更新规则、检索、注入和遗忘。
- 查看命中日志和成本。
- 归档和恢复。

手工记忆与自动槽位：

- 单条和批量新增。
- 查询、编辑、启停、删除和恢复。
- 查看修订历史和命中次数。

### 24.9 测试集与测试案例

测试集：

- 新建、复制、导入、导出。
- 编辑草稿。
- 保存版本。
- 归档、恢复和删除。

测试案例：

- 新建单轮或连续场景。
- 从历史对话或 Bad Case 添加。
- 批量编辑标签、分类和负责人。
- 移动或复制到其他测试集。
- 删除和恢复。

边界：

- 修改正式测试集创建新版本。
- 案例被运行引用时删除只影响后续版本。
- 导入重复案例提供去重预览。

### 24.10 评分卡

- 新建、复制内置评分卡。
- 编辑维度、权重、锚点、封顶规则和发布门槛。
- 自动校验权重总和。
- 保存版本。
- 归档和恢复。
- 查看评分卡使用的运行和报告。

边界：

- 已运行评分卡不可原地修改。
- 改变评分卡后旧分和新分不直接合并。
- 删除维度前显示历史数据影响。

### 24.11 评测定义与运行

评测定义：

- 新建、复制、修改草稿、删除草稿。
- 选择旧版、新版、测试集和共享条件。
- 保存为可复用模板。

评测运行：

- 启动、暂停、继续、取消和重跑。
- 查询、筛选、标注、归档和恢复。
- 复制运行配置创建新运行。
- 不允许编辑已经产生的回复和原始分数。

### 24.12 报告

- 新建空白报告。
- 从单次或多次兼容运行生成。
- 复制报告模板。
- 编辑标题、结论、案例和展示配置。
- 保存修订版。
- 归档、移入回收站和恢复。
- 导出 Markdown、CSV 和 JSON。

边界：

- 自动指标不可手工篡改，只能选择数据源。
- 数据源变化后显示过期提示。
- 删除来源运行时报告保留快照。

### 24.13 团队成员、角色和权限

- 邀请单个成员。
- 批量导入成员。
- 搜索、筛选和查看活动。
- 修改工作空间和项目角色。
- 移除、暂停和重新邀请。
- 查看权限来源。

边界：

- 不能移除最后一名所有者。
- 用户不能提升自己到无权授予的角色。
- 移除成员不删除其历史内容和审计记录。

### 24.14 标签、评论和保存视图

标签：

- 新建、编辑、合并、删除和批量应用。

评论：

- 新建、回复、编辑自己的评论、解决、重新打开和软删除。

保存视图：

- 创建、复制、重命名、修改筛选、调整共享范围和删除。

## 25. 资源状态与操作可用性

### 25.1 通用资源状态

```text
草稿
  → 使用中
  → 已归档
  → 回收站
  → 永久删除

已归档 → 恢复为使用中
回收站 → 恢复到删除前状态
```

### 25.2 状态决定操作

| 状态 | 可编辑 | 可用于新运行 | 可归档 | 可删除 | 可恢复 |
| --- | --- | --- | --- | --- | --- |
| 草稿 | 是 | 否 | 是 | 是 | 否 |
| 使用中 | 按资源类型 | 是 | 是 | 视依赖 | 否 |
| 已归档 | 否或创建新草稿 | 可作为历史基线 | 否 | 是 | 是 |
| 回收站 | 否 | 否 | 否 | 管理员永久删除 | 是 |
| 不可变证据 | 否 | 仅供引用 | 否 | 否 | 否 |

## 26. 通用表单与错误边界

### 26.1 表单校验

- 必填、长度、格式和跨字段依赖即时校验。
- 服务端业务校验返回具体字段和可修复原因。
- 第一次提交后聚焦首个错误。
- 多标签错误在标签上显示数量。
- 后端失败不清空用户输入。

### 26.2 操作反馈

- 小型成功操作使用短暂 Toast。
- 后台任务显示任务入口和进度。
- 需要用户处理的失败保留在页面，不只显示会消失的 Toast。
- 批量操作生成可下载结果。

### 26.3 并发冲突

- 编辑请求携带资源版本号。
- 版本号过期返回冲突，而不是覆盖。
- 冲突页面显示自己和他人的修改。
- 支持字段级合并、保存为副本或放弃。

### 26.4 权限变化

- 用户编辑过程中权限被移除时，保留本地草稿并切换只读。
- 用户可导出自己的未提交内容，但不能绕过权限写回。
- 列表中的不可用操作显示权限原因。

## 27. CRUD 验收清单

每种业务资源上线前必须逐项通过：

1. 能从空白创建。
2. 能从已有对象复制。
3. 能在列表查询、搜索、筛选、排序和分页。
4. 能打开详情并查看引用和审计记录。
5. 能按资源规则修改或创建新版本。
6. 能处理两人同时编辑。
7. 能归档和恢复。
8. 能移入回收站和恢复。
9. 能正确阻止破坏依赖的永久删除。
10. 能批量处理允许的操作并报告部分失败。
11. 能在无权限时正确隐藏或禁用操作。
12. 能在网络失败后保留输入。
13. 能导入和导出。
14. 所有写操作有审计记录。
15. 历史运行和发布证据不因资源修改或删除而变化。

## 1. 设计目标

平台的核心任务不是让用户“跑一次模型”，而是帮助团队可靠地回答：

> 新版本是否比旧版本更好，好在哪里，差在哪里，证据是否足以发布？

所有页面和交互都围绕固定双版本比较：

- 旧版本：基线。
- 新版本：候选。
- 其他条件：锁定一致。
- 结果：旧分、新分、分差、缺陷变化和案例证据。

### 1.1 用户体验原则

1. **双版本始终可见。** 页面顶部持续显示旧版本、新版本和生产版本，避免比较对象漂移。
2. **先保证可比，再开始评测。** 模型、角色、世界观、历史窗口、调度、记忆和输入不一致时阻止运行。
3. **先展示结论，再允许下钻。** 默认显示分差与关键回退，需要时再查看单轮回复、最终 Prompt 和模型原文。
4. **不隐藏失败。** 模型失败、评分失败和数据缺失不能伪装成 0 分或正常结果。
5. **原始数据不可覆盖。** 人工改分、备注和修复建议以附加记录保存。
6. **长任务可离开。** 用户关闭页面或切换模块不会终止运行，重新进入可继续查看。
7. **不抢用户操作。** 页面不自动滚动到最底部，不因新消息打断正在阅读的内容。
8. **危险动作可恢复。** 删除、清空、取消和回滚都要区分影响范围并提供恢复路径。
9. **默认简单，高级能力渐进展开。** 新用户可使用预设完成评测，专业用户可配置规模、并发、评分和成本。
10. **分数必须有证据。** 每个扣分都要关联原文片段、规则或流程事件。

## 2. 用户心智模型

用户不需要理解内部 Builder、Socket 事件或脚本名称，只需要理解六个概念：

1. **项目**：一个产品或业务方向。
2. **Prompt**：持续迭代的提示词资产。
3. **版本**：不可变的旧版或新版。
4. **测试集**：用什么问题和对话来测试。
5. **评测运行**：实际生成、评分和记录的过程。
6. **发布**：把验证通过的新版本设为生产版本。

主流程：

```text
选择项目
  → 进入 Prompt
  → 选择旧版本和新版本
  → 选择测试集与运行规模
  → 通过运行前检查
  → 执行生成与评分
  → 查看分差、回退和案例
  → 人工复核
  → 发布或继续修改
```

## 3. 信息架构

### 3.1 一级导航

| 导航 | 主要任务 |
| --- | --- |
| 项目 | 查看项目状态、最近活动和生产版本 |
| Prompt | 编辑 Prompt、管理版本和查看 Diff |
| 测试集 | 管理单轮案例与连续对话场景 |
| 评测 | 新建评测、查看运行中和历史运行 |
| 报告 | 查看、生成、导出和分享报告 |
| 发布 | 查看生产版本、发布审批和回滚记录 |
| 设置 | 模型连接、成员、预算、评分卡和数据策略 |

项目内页面保留相同左侧导航，顶部面包屑显示：

`工作空间 / 项目 / Prompt / 当前页面`

### 3.2 全局顶部栏

- 当前工作空间和项目切换。
- 全局搜索：Prompt、版本、运行、案例和报告。
- 运行任务入口：显示运行中、排队和失败数量。
- 服务状态：模型可用性、队列状态和预算告警。
- 通知：评测完成、评审请求、发布结果和失败。
- 用户菜单：身份、偏好和退出。

### 3.3 全局状态提示

只使用四类状态色，并始终配合文字或图标：

- 蓝色：进行中或信息。
- 绿色：通过或正向提升。
- 黄色：需复核或存在风险。
- 红色：失败、阻断或显著回退。

分差颜色按指标方向计算：

- 分数越高越好：正数为绿色，负数为红色。
- 缺陷率、延迟、成本越低越好：负数为绿色，正数为红色。

不能单纯按正负号着色。

## 4. 首次使用流程

### 4.1 空工作空间

首次进入时不展示空白图表，显示三个明确动作：

1. 创建项目。
2. 导入现有 Prompt 和历史数据。
3. 使用示例项目体验完整流程。

示例项目必须与真实数据隔离，可以一键删除，不写入生产配置。

### 4.2 创建项目

必填：

- 项目名称。
- 项目负责人。

选填：

- 项目描述。
- 默认模型配置。
- 默认评分卡。
- 默认角色集和世界观。

创建成功后进入项目概览，并展示下一步“创建或导入 Prompt”。

边界：

- 名称重复允许，但提示同名项目。
- 名称为空、仅空格或超长时前端即时提示。
- 创建请求重复提交使用幂等键，只创建一个项目。
- 网络失败保留表单内容。

### 4.3 导入旧数据

支持导入：

- 当前 `config.json`。
- 当前 Prompt 工作区 JSON。
- 历史评测 JSON。
- Markdown 报告，仅作为文档附件，不自动伪造结构化分数。

导入流程：

1. 选择文件。
2. 预览识别结果。
3. 显示将创建、合并、跳过和冲突的对象数量。
4. 用户确认映射。
5. 执行导入。
6. 输出导入报告和可撤销批次。

冲突处理：

- 相同内容使用哈希去重。
- 同名不同内容创建独立版本，不覆盖。
- 无法识别的字段保存到原始导入附件。
- 编码异常先尝试 UTF-8 检测，不静默替换乱码。

## 5. 项目概览

### 5.1 页面目标

让负责人在 30 秒内知道：

- 当前生产版本是什么。
- 最新候选版本是什么。
- 最近一次新旧对比是否提升。
- 是否存在阻断发布的问题。
- 最近有哪些运行、评审和发布活动。

### 5.2 页面结构

顶部摘要：

- 生产版本。
- 最新候选版本。
- 最近一次总分变化。
- 发布门槛状态。
- 本月模型调用和成本。

中部：

- 最近 30 天新旧版本分数趋势。
- 严重缺陷趋势。
- 最近评测运行。
- 待处理评审。

底部：

- 项目活动时间线。
- 最近 Good Case 和 Bad Case。

空状态：

- 没有 Prompt：引导创建 Prompt。
- 有 Prompt 无新版本：引导从生产版本创建新版本。
- 有新版本无评测：引导新建评测。
- 有评测无人工复核：引导处理高风险案例。

## 6. Prompt 资产与版本

### 6.1 Prompt 列表

每行显示：

- Prompt 名称和用途。
- 当前生产版本。
- 最新草稿版本。
- 最近评测分差。
- 负责人。
- 更新时间。
- 风险状态。

支持：

- 按负责人、标签、状态和是否有回退筛选。
- 搜索名称、描述和版本说明。
- 收藏常用 Prompt。
- 批量归档，不支持批量发布。

### 6.2 Prompt 编辑器

页面三栏：

- 左栏：Prompt 结构与变量。
- 中栏：模板编辑器。
- 右栏：版本信息、预览上下文和检查结果。

编辑能力：

- 变量高亮。
- 变量自动补全。
- 未知变量报错。
- 结构段落导航。
- 搜索与替换。
- 撤销与重做。
- 草稿自动保存。
- 最终渲染预览。

草稿状态：

- 页面顶部显示“未保存为版本”。
- 自动保存只保存草稿，不产生版本号。
- 评测只能选择不可变版本，不能直接运行浮动草稿。
- 用户点击“开始评测”时若存在未版本化改动，引导先保存新版本。

离开页面：

- 草稿已自动保存：可直接离开。
- 自动保存失败：明确提示并阻止无提示离开。
- 多标签页同时编辑：检测版本冲突，禁止最后写入覆盖。

### 6.3 保存新版本

必须填写：

- 版本名称。
- 改动说明。
- 预期改善指标。

可选：

- 关联需求或问题。
- 风险说明。
- 标签。

保存后：

- 创建不可变版本。
- 草稿基线切换到新版本。
- 提供“与来源版本比较”和“开始新旧评测”。

重复保存：

- 内容完全相同则提示已存在相同版本。
- 允许用户取消或明确创建重复快照用于审计。

### 6.4 版本历史

版本列表显示：

- 版本号和名称。
- 草稿、候选、已发布、已归档状态。
- 来源版本。
- 作者和时间。
- 最近评测分数。
- 是否满足发布门槛。

操作：

- 查看。
- 与任意旧版本比较。
- 基于此版本创建新草稿。
- 设为评测旧版或新版。
- 归档和恢复。
- 发布或回滚。

限制：

- 已发布版本不可删除，只能归档。
- 被运行、报告或发布记录引用的版本不可物理删除。
- 归档版本仍可作为旧版基线。
- 新版时间可以早于旧版时间，但显示“反向比较”警告。

### 6.5 版本 Diff

Diff 分为四个标签：

1. Prompt 文本。
2. 变量协议。
3. 元数据和版本说明。
4. 最终渲染 Prompt。

默认只突出真实变化，不把换行格式化全部显示为修改。

可选择：

- 并排 Diff。
- 行内 Diff。
- 只看变化。
- 忽略空白差异。

## 7. 新建评测

新建评测采用分步流程，但用户可返回修改前一步。

### 7.1 第一步：选择版本

左侧选择旧版本，右侧选择新版本。

默认值：

- 旧版默认当前生产版本。
- 新版默认最近创建且未发布的版本。

每侧显示：

- 版本号、名称、作者和时间。
- 最近总分。
- 生产或候选状态。
- 与另一版本的 Prompt 变化摘要。

边界：

- 两侧选择同一版本时，正常评测不可继续。
- 平台可在高级入口提供“同版本稳定性校准”，但必须标记为校准，不产生发布结论。
- 新版不存在时提供“从旧版创建新版本”。
- 旧版已归档允许继续使用。
- 版本属于不同 Prompt 时禁止比较。

### 7.2 第二步：选择测试方式

预设：

| 模式 | 输入方式 | 默认规模 |
| --- | --- | ---: |
| 冒烟检查 | 固定单轮案例 | 4 例 |
| 快速体验 | 真人连续输入 | 最多 10 轮 |
| 标准评测 | 固定或 AI 模拟玩家 | 20 轮 |
| 正式评测 | 固定或 AI 模拟玩家 | 60 轮 |
| 专项评测 | 指定分类测试集 | 由测试集决定 |

用户选择：

- 测试集版本。
- 运行轮数或案例范围。
- 每案例重复次数。
- 真人输入、固定脚本或 AI 模拟玩家。

### 7.3 第三步：锁定运行条件

页面显示共享配置，不分左右两套：

- 角色集。
- 世界观。
- 模型与采样参数。
- 历史窗口。
- 调度规则。
- 记忆策略。
- 评分卡。
- 并发和重试策略。

任何修改同时影响两侧。

高级设置折叠显示：

- 温度。
- Presence penalty。
- 最大输出长度。
- 超时。
- 重试次数。
- 并发上限。
- 成本上限。
- 随机种子或共享随机策略。

### 7.4 第四步：运行前检查

检查结果分三类：

- 通过：可以运行。
- 警告：允许运行，但需要明确确认。
- 阻断：必须修复。

阻断项：

- 未解析变量。
- Prompt 为空。
- 没有角色。
- 模型连接不可用。
- 测试集为空。
- 评分卡无维度。
- 旧版与新版不是同一 Prompt。
- 两侧运行条件不一致。
- 预计成本超过硬上限。

警告项：

- 两版 Prompt 内容完全相同。
- 新版早于旧版。
- 测试样本过少。
- 温度较高但重复次数为 1。
- 正式评测未开启人工复核。
- 记忆评测没有设置延迟回忆案例。
- 世界观变量为空。

页面同时显示：

- 预计模型调用次数。
- 预计评分调用次数。
- 预计 Token。
- 预计费用区间。
- 预计完成时间。
- 会保存哪些原始数据。

用户点击“开始评测”后创建不可变运行快照。此后编辑 Prompt 或设置不影响当前运行。

## 8. 运行中体验

### 8.1 通用运行状态

状态机：

```text
草稿
  → 排队中
  → 运行中
  → 评分中
  → 待人工复核
  → 已完成

运行中可进入：
  → 暂停
  → 已取消
  → 部分完成
  → 失败
```

页面顶部固定显示：

- 旧版与新版。
- 已完成轮数 / 总轮数。
- 当前阶段。
- 成功、失败和待重试数量。
- 已用时间和预计剩余时间。
- 已用 Token 和费用。
- 暂停、取消和后台运行。

### 8.2 自动批量运行

主体区域：

- 左侧：轮次和案例列表。
- 中间：旧版与新版当前回复。
- 右侧：当前调用详情和实时日志。

轮次列表状态：

- 等待。
- 生成中。
- 评分中。
- 完成。
- 部分失败。
- 需复核。

用户可：

- 查看已完成轮次。
- 只看失败。
- 暂停新任务入队。
- 对失败任务单独重试。
- 取消剩余任务并保留已完成数据。

不允许：

- 修改运行快照。
- 删除正在运行的版本。
- 用重试结果覆盖第一次失败记录。

### 8.3 真人连续对话

布局：

- 左列旧版本聊天室。
- 右列新版本聊天室。
- 底部共享玩家输入框。
- 右侧抽屉查看本轮 Prompt、调度、记忆和评分。

输入规则：

- 同一条玩家消息同时发送到两侧。
- 发送后立刻显示用户消息，不等待 AI。
- 发送期间输入框仍允许撰写下一条，但明确显示“将在下一轮发送”。
- Enter 发送，Shift+Enter 换行。
- 支持 @ 角色标签。
- 显示 3 秒消息打包倒计时和已进入本轮的真人消息。

滚动规则：

- 用户在底部时，新消息自动跟随。
- 用户向上阅读后停止自动滚动。
- 新消息到达时显示“有新消息”按钮。
- 两侧独立滚动。
- 提供临时“同步滚动”开关用于逐轮比较。
- 初次进入不自动跳到最底部，恢复上次阅读位置。

真人输入边界：

- 空消息和仅空格不发送。
- 超长输入显示长度并阻止超限。
- 重复点击发送只产生一个消息。
- 断网时消息进入本地待发送状态，不伪装成已提交。
- 用户撤回尚未进入打包窗口的消息可取消；已进入运行快照的消息不可删除，只能标记撤回。
- @ 已移出角色时发送前阻断并要求重新选择。
- 一侧失败不阻止另一侧展示，但该轮标记不可直接比较。

### 8.4 多人在线输入

- 显示在线成员和正在输入状态。
- 3 秒窗口内的真人消息在两侧使用相同打包结果。
- 打包结果展开可查看原始消息、作者和时间。
- 同一成员多设备连接视为同一身份但不同连接。
- 成员断线不删除已提交消息。
- 房主离开不终止运行。
- 权限不足成员只能观看，不能发送或控制运行。

### 8.5 主动线

- 页面显示主动线下一次预计触发时间。
- 玩家开始输入不重置计时，只有成功提交消息才重置。
- 主动线触发前若有玩家消息进入打包窗口，则取消本次主动任务。
- 主动回复达到上限后显示“主动线已停止，等待玩家发言”。
- 两侧使用相同的主动角色抽取结果和触发时间。

## 9. 失败、暂停与恢复

### 9.1 模型生成失败

单侧失败：

- 另一侧结果保留。
- 当前轮标记“不可直接比较”。
- 显示失败类型：超时、限流、认证、空回复、内容过滤或未知错误。
- 允许只重试失败侧。
- 重试生成新的尝试记录，不覆盖原始失败。

双侧失败：

- 当前轮不进入文本质量平均分。
- 计入服务可用性指标。
- 达到连续失败阈值后自动暂停运行。

### 9.2 评分失败

- 保留生成结果。
- 当前轮显示“未评分”，不能按 0 分处理。
- 允许更换评分模型后重试评分。
- 更换评分模型会创建新的评分批次，旧评分仍可查看。

### 9.3 页面关闭或刷新

- 运行由服务端继续。
- 重新进入时恢复最新状态。
- 未发送的本地草稿输入按项目和运行保存。
- 页面刷新不重复提交开始运行请求。

### 9.4 服务重启

- 未开始任务恢复排队。
- 已完成模型调用不重复执行。
- 无法确认状态的调用标记“中断待确认”。
- 用户选择重试后创建新尝试。
- 运行最终可处于“部分完成”，允许分析现有结果。

### 9.5 暂停与取消

暂停：

- 不再启动新模型调用。
- 已发出的调用允许完成并保存。
- 可恢复。

取消：

- 要求确认影响范围。
- 尽力取消未开始和可取消的请求。
- 已完成数据保留。
- 运行状态变为“已取消”，不可恢复，只能复制配置重新运行。

## 10. 结果分析

### 10.1 结果页首屏

首屏必须直接回答：

- 新版是否更好。
- 提升多少。
- 是否满足发布门槛。
- 哪些指标显著回退。
- 样本量是否足够。

顶部结论卡：

- 旧版总分。
- 新版总分。
- 分差和提升百分比。
- 置信或稳定性提示。
- 关键缺陷变化。
- 发布建议：建议发布、需复核、不建议发布。

结论不能只根据总分。若玩家行动权、角色边界、世界观或 @ 准确性触发红线，即使总分提升也不能显示“建议发布”。

### 10.2 指标对比

默认视图：

- 十维评分表。
- 新旧分差。
- 缺陷率变化。
- 调度准确性。
- 延迟和成本。

图表：

- 十维雷达图。
- 各轮分数折线图。
- 分数分布。
- 缺陷率对比。
- 回复长度、延迟、Token 和成本趋势。

图表交互：

- 悬停显示样本量和计算口径。
- 点击指标筛选对应案例。
- 显示“越高越好”或“越低越好”。
- 缺失数据不连接成趋势线。
- 样本量不足时不展示虚假百分比精度。

### 10.3 案例对比

案例列表默认排序：

1. 严重回退。
2. 一票否决。
3. 评分分歧。
4. 显著提升。
5. 其余案例。

每个案例显示：

- 玩家输入和前置上下文。
- 旧版回复。
- 新版回复。
- 两侧维度分和分差。
- 缺陷标签。
- AI 评分依据和原文引用。
- 调度、角色和历史窗口。
- 延迟、Token 和成本。

操作：

- 标记 Good Case。
- 标记 Bad Case。
- 加入回归集。
- 添加人工评论。
- 修改人工评分。
- 请求其他评审者复核。
- 查看完整原始数据。

### 10.4 原始数据抽屉

按调用分层展示：

1. 运行快照。
2. 玩家原始消息与打包结果。
3. 角色抽取和调度事件。
4. 变量值。
5. 最终渲染 Prompt。
6. 模型原始响应。
7. 清洗后响应。
8. AI 评分请求和原始响应。
9. 人工评分和修订历史。
10. Token、延迟、错误和重试。

默认格式化展示，并提供原始 JSON。

敏感信息：

- API Key 永不展示。
- 用户隐私字段按权限脱敏。
- 导出前显示将包含的数据范围。

## 11. 人工评审

### 11.1 评审队列

自动进入队列的案例：

- 一票否决。
- 新版显著低于旧版。
- AI 评分解析异常。
- 两名 AI Judge 分差过大。
- 人工与 AI 分差过大。
- 生成失败或单侧缺失。
- 世界观、角色边界和玩家行动权高风险。

### 11.2 人工评分

- 评分者逐维打分。
- 修改分数必须填写理由。
- 可引用回复片段。
- 可选择缺陷标签。
- 保存后保留 AI 原分和人工分。
- 最终报告默认使用已确认人工分，否则使用 AI 分并标注。

### 11.3 多人评审冲突

- 每位评审独立提交，提交前不显示他人分数，减少锚定。
- 总分差超过 10 分自动进入仲裁。
- 仲裁者选择最终分或重新评分。
- 所有评分和理由永久保留。

## 12. 报告流程

### 12.1 生成报告

用户选择：

- 使用哪些运行。
- 使用 AI 分还是人工确认分。
- 是否包含成本和延迟。
- Good/Bad Case 数量。
- 是否包含原始数据链接。

系统自动生成：

- 评测目标。
- 版本差异。
- 方法、样本量和控制变量。
- 旧分、新分、分差和提升百分比。
- 十维与缺陷率表格。
- Good Case 和 Bad Case。
- 低分原因与修复建议。
- 风险和发布建议。

### 12.2 报告编辑

- 自动生成内容可编辑。
- 自动数据区块与手写结论区分。
- 运行数据更新后提示报告已过期，不自动改写人工结论。
- 可重新同步图表和指标。
- 支持 Markdown、JSON 和 CSV 导出。

### 12.3 报告边界

- 部分完成运行可生成报告，但必须显示完成比例。
- 使用不同评分卡的运行不能直接合并平均分。
- 使用不同模型或测试集时显示不可严格归因警告。
- 删除或归档来源运行后，报告仍保留快照和引用。

## 13. 发布流程

### 13.1 发布前页面

显示：

- 当前生产旧版本。
- 待发布新版本。
- 最新正式评测结果。
- 样本量。
- 发布门槛。
- 所有阻断项和警告项。
- 审批状态。

阻断发布：

- 没有正式评测。
- 评测不是当前候选版本。
- 严重缺陷超出门槛。
- 未完成要求的人工复核。
- 模型或运行配置与生产目标不兼容。
- 候选版本已归档。

### 13.2 发布确认

确认弹窗明确展示：

- 将替换的生产版本。
- 新版本。
- 生效环境。
- 关联报告。
- 回滚目标。

发布请求使用幂等键，重复点击不能产生重复发布记录。

### 13.3 发布后

- 新版本成为生产版本。
- 旧生产版本进入历史，不删除。
- 聊天室读取完整发布快照。
- 生成发布记录和审计事件。
- 提供上线后冒烟检查入口。

### 13.4 回滚

- 从发布历史选择目标版本。
- 显示目标版本最后一次评测和已知风险。
- 回滚本身创建新的发布事件。
- 回滚不删除失败版本。
- 回滚后可对失败版本继续创建新草稿。

## 14. 删除、清空与归档

不同动作必须使用不同语言：

- 清空输入草稿：只删除本地未发送文本。
- 重启会话：创建新 Session，旧聊天只读保留。
- 取消运行：停止剩余任务，保留结果。
- 归档：从默认列表隐藏，可恢复。
- 删除：进入回收站，保留期限内可恢复。
- 永久删除：管理员操作，明确列出受影响对象。

依赖保护：

- 被发布记录引用的版本不能永久删除。
- 被报告引用的运行只能软删除。
- 删除测试集不影响历史运行快照。
- 删除项目需输入项目名称确认，并先显示对象数量、数据大小和影响。

## 15. 搜索、筛选与批量操作

### 15.1 搜索

支持搜索：

- Prompt 名称和内容。
- 版本说明。
- 运行 ID。
- 玩家输入和 AI 回复。
- 缺陷标签。
- 报告标题。

搜索结果按对象类型分组，避免把版本和运行混在一起。

### 15.2 筛选

运行筛选：

- 状态。
- 时间。
- 旧版和新版。
- 测试集。
- 模型。
- 负责人。
- 总分变化。
- 是否存在严重回退。

案例筛选：

- 分数区间。
- 分差。
- 角色。
- 触发线。
- 缺陷。
- Good/Bad Case。
- 是否人工复核。

筛选条件写入 URL，刷新和分享后可恢复。

### 15.3 批量操作

允许：

- 批量归档运行。
- 批量加入评审队列。
- 批量添加标签。
- 批量导出。

禁止：

- 批量发布。
- 批量永久删除生产相关资产。
- 跨评分卡批量计算平均分。

## 16. 权限与协作

### 16.1 权限矩阵

| 操作 | 查看者 | 编辑者 | 评审者 | 管理员 |
| --- | --- | --- | --- | --- |
| 查看 Prompt 和运行 | 是 | 是 | 是 | 是 |
| 编辑草稿 | 否 | 是 | 是 | 是 |
| 创建版本 | 否 | 是 | 是 | 是 |
| 启动评测 | 否 | 是 | 是 | 是 |
| 人工评分 | 否 | 可选 | 是 | 是 |
| 发布 | 否 | 否 | 按项目配置 | 是 |
| 永久删除 | 否 | 否 | 否 | 是 |

### 16.2 协作边界

- Prompt 版本不可变，避免多人覆盖。
- 草稿使用乐观锁和冲突提示。
- 同一运行可多人观看。
- 运行控制操作显示操作者。
- 评论支持回复和解决状态。
- 已解决评论在新版本中仍可追溯。

## 17. 模型、预算与服务状态

### 17.1 模型连接

- 测试连接按钮返回延迟和模型列表。
- Key 只显示已配置状态，不回显原文。
- 切换模型前展示可能影响可比性的提示。
- 模型被删除时，历史运行继续显示模型快照。

### 17.2 预算

- 工作空间月预算。
- 项目预算。
- 单次运行硬上限。
- 接近上限时警告。
- 达到上限时暂停未开始任务。
- 管理员追加预算后可恢复。

### 17.3 服务状态

全局状态分为：

- 正常。
- 降级：部分模型或评分不可用。
- 不可用。

错误信息包含可行动建议，例如：

- 认证失败：检查服务端模型连接。
- 额度不足：联系管理员或切换配置。
- 限流：等待自动重试或降低并发。
- 超时：查看原始调用并重试。

不向普通用户展示堆栈和密钥相关内容。

## 18. 响应式与可访问性

### 18.1 桌面

- 主要设计目标为 `1280px` 以上。
- 双版本聊天和案例对比保持左右布局。
- 右侧详情使用抽屉，避免压缩主内容。

### 18.2 窄屏

- 小于 `1024px` 时旧版和新版使用顶部切换，但保留分数差摘要。
- 提供“并排查看”横向滚动模式。
- 不将双版本简单堆成长页面，避免失去对应关系。

### 18.3 可访问性

- 所有图表提供数据表。
- 状态不只依赖颜色。
- 键盘可完成编辑、选择版本、发送消息和评审。
- 弹窗打开后焦点进入弹窗，关闭后回到原操作。
- 图标按钮有可访问名称和 Tooltip。
- 长文本可换行，不遮挡按钮和分数。

## 19. 文案规范

避免模糊状态：

- 不使用“不可用”，应说明“生成模型认证失败”或“评分模型超时”。
- 不使用“运行失败”，应说明失败轮数和可恢复方式。
- 不使用“清空记录”，应说明“重启会话并创建新的上下文”。
- 不使用“保存”，区分“保存草稿”和“保存新版本”。
- 不使用“对比方案 A/B”，统一使用“旧版本/新版本”。

核心按钮：

- 保存草稿。
- 保存新版本。
- 开始新旧评测。
- 暂停运行。
- 取消剩余任务。
- 查看原始数据。
- 请求人工复核。
- 发布新版本。
- 回滚到此版本。

## 20. 完整边界情况矩阵

| 场景 | 系统行为 |
| --- | --- |
| 没有生产版本 | 允许手动选择任一历史版为旧版，并标记“非生产基线” |
| 只有一个版本 | 引导从该版本创建新版本，不允许正常对比同一版本 |
| 新旧内容完全一致 | 警告并建议稳定性校准，正式评测需明确确认 |
| 新版创建时间更早 | 允许反向比较，但不默认作为发布候选 |
| Prompt 有未解析变量 | 阻断运行并定位到变量位置 |
| 测试集为空 | 阻断运行 |
| 测试集运行中被修改 | 当前运行继续使用旧快照 |
| 角色被移出 | 新运行不再选择；历史运行保持原角色快照 |
| @ 角色不存在 | 发送前阻断 |
| 模型 Key 失效 | 阻断新运行，运行中任务按失败策略处理 |
| 一侧生成失败 | 另一侧保留，该轮标记不可直接比较 |
| Judge 失败 | 回复保留，分数标记缺失，不计 0 分 |
| AI Judge 返回非法 JSON | 保存原文并进入人工复核 |
| AI 与人工分差很大 | 显示双方分数并进入仲裁 |
| 用户刷新页面 | 服务端运行继续，页面恢复状态 |
| 用户关闭浏览器 | 服务端运行继续并发送完成通知 |
| 服务端重启 | 恢复队列或标记中断，不重复已确认调用 |
| 重复点击开始 | 幂等处理，只创建一个运行 |
| 预算在运行中耗尽 | 暂停未开始任务，保留已完成数据 |
| 取消正式评测 | 保留部分结果，不允许将其作为正式发布依据 |
| 运行只有部分案例完成 | 允许分析，报告明确完成率 |
| 两次运行评分卡不同 | 禁止直接合并平均分 |
| 两次运行模型不同 | 允许查看，但提示不能归因于 Prompt |
| 删除版本 | 有引用时只能归档 |
| 删除运行 | 软删除，报告引用保持 |
| 清空聊天 | 创建新 Session，取消旧 Session 待完成请求 |
| 两人同时编辑草稿 | 检测冲突，要求合并或另存版本 |
| 两人同时发布 | 使用锁和幂等校验，后提交者重新确认生产版本 |
| 发布时生产版本已变化 | 阻断并重新展示新基线 |
| 发布后冒烟失败 | 显示紧急回滚入口和失败案例 |
| 历史数据乱码 | 导入预览阻断，要求确认编码转换 |
| 原始数据过大 | 分页和按需加载，不截断持久化数据 |
| 图表无数据 | 显示原因和下一步，不显示 0 分假象 |
| 移动端查看双版本 | 使用版本切换和固定分差摘要 |

## 21. 关键验收场景

### 21.1 新用户首轮评测

1. 创建项目。
2. 导入旧 Prompt。
3. 从旧版创建新版。
4. 保存不可变版本。
5. 选择旧版与新版。
6. 使用 4 例冒烟集。
7. 运行前检查通过。
8. 完成生成与评分。
9. 查看总分差和 Bad Case。
10. 将 Bad Case 加入回归集。

全流程不需要进入聊天室、记忆页或执行脚本。

### 21.2 20 轮真人体验

1. 选择旧版与新版。
2. 锁定共享角色、世界观和模型。
3. 进入左右双栏。
4. 真人根据实际回复连续发言 20 轮。
5. 两侧使用相同角色抽取和触发线。
6. 页面不抢滚动位置。
7. 结束后自动进入评分。
8. 查看玩家行动权、问句滥用和 AI 淹没率。

### 21.3 失败恢复

1. 第 8 轮新版模型超时。
2. 旧版结果正常保存。
3. 运行继续后续轮次。
4. 用户只重试第 8 轮新版。
5. 原始失败与重试成功均可查看。
6. 报告使用确认后的成功尝试，并标注重试。

### 21.4 发布与回滚

1. 新版正式评测达到门槛。
2. 高风险案例人工复核完成。
3. 发布页显示新旧差异和报告。
4. 发布成功后生产聊天室使用新快照。
5. 上线冒烟失败。
6. 用户回滚到上一生产版本。
7. 两次发布事件和原因完整保留。
