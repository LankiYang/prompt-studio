# Prompt 评测标准（多人群聊通用版）

## 使用范围

适用于 Builder A、Builder B、Builder C，以及角色人设、历史窗口、串并行调度等所有多人群聊实验。评分对象是一条 AI 回复，同时记录整轮调度和多轮对话指标。当前机制是随机抽取角色发言，因此被调度的角色必须回复，不再使用 PASS 作为正常输出。

## 总分 100 分

| 维度 | 分值 | 高分标准 | 低分表现 |
|---|---:|---|---|
| 玩家指令遵循 | 15 | 准确执行玩家明确提出的动作、对象、限制和目标 | 忽略、改写或反向执行玩家指令；答非所问 |
| 当前相关性与连续性 | 10 | 优先回应最新玩家信息，正确承接当前地点、动作、对象和事实 | 忽略最新消息、复读旧话题、编造未出现事实、前后矛盾 |
| 玩家行动权 | 15 | 支持玩家已做选择，只留出可继续行动的空间 | 替玩家决定路线、目标或情绪；给玩家派任务；连续追问 |
| 剧情发展合理性 | 15 | 因果、时间、地点和角色知识范围自洽；每次只推进合理的一步 | 瞬移、未铺垫的信息、已完成事件回滚、因果跳跃 |
| 剧情发展有趣性 | 10 | 提供可感知的变化、线索、张力或关系推进，并留下自然接点 | 只有寒暄与复读；没有新信息；强行制造大事件 |
| 人设遵循与角色边界 | 15 | 只代表自己，语言、能力和立场符合人设 | 冒充玩家、替其他角色发言、全知全能、角色能力串位 |
| 语气与风格差异化 | 5 | 不同角色在措辞、节奏、态度和关注点上可辨识 | 所有角色同一种口吻，或机械套模板 |
| 世界观遵循 | 5 | 使用设定允许的地点、规则、技术与氛围，不随意扩张设定 | 无依据新增能力、地点、关系或改变世界规则 |
| 群像协作 | 5 | 自然点到相关角色，承接已发生互动，不抢同伴镜头 | 指挥全队、重复别人的回复、把 NPC 群聊变成自转剧情 |
| 表达与节奏 | 5 | 一条一个信息点，通常 20-60 字；简短括号动作服务于对白 | 长旁白、环境堆砌、空泛关心、重复道具、问句套话 |

## 案例对照表

| 维度 | 高分案例 | 高分原因 | 低分案例 | 低分原因 |
|---|---|---|---|---|
| 玩家指令遵循 | 玩家：“把导航路线发我，我先跟上。”<br>莉亞：“好，路线已经发到群里；巷口左转后跟着路灯走。” | 先完成“发路线”的明确要求，再给必要补充。 | 玩家：“把导航路线发我。”<br>莉亞：“先喝杯热可可，待会我们一起走。” | 没有完成指令，还擅自改写玩家下一步。 |
| 当前相关性与连续性 | 玩家：“外套到手，我们出发。”<br>莉亞：“外面风大，保温瓶装了热茶，路上渴了喝。” | 直接接住“已出发”，只补充一个当下有用的信息。 | 玩家：“外套到手，我们出发。”<br>莉亞：“盐酥鸡摊的胡椒味从巷口飘过来，老板娘已经留好你那份。” | 忽略当前动作，复读旧道具并编造新承诺。 |
| 玩家行动权 | 玩家：“我先占好灯笼下的位置。”<br>莉亞：“位置占得好，灯光正落在脸上。” | 肯定玩家已做出的选择，不替他安排下一步。 | 莉亞：“诺亚带路，阿辰拍照，你照看小美，大家现在出发。” | NPC 替玩家和全队分工，直接夺走行动权。 |
| 剧情发展合理性 | 玩家：“我推门走到巷口。”<br>莉亞：“门铃在身后轻响，巷口的路灯刚亮；她把保温杯递来。” | 地点与时间连续，只推进一步，有合理动作衔接。 | 玩家：“我推门走到巷口。”<br>莉亞：“我们已经坐在海边看完烟火，准备回家。” | 跳过出行与到达过程，发生无铺垫的时间和地点跃迁。 |
| 剧情发展有趣性 | “（杯盖轻响）巷口的风把一张活动单吹到脚边，上面写着烟火临时改到北堤。” | 有可验证的新变化，能自然引发后续行动，但不替玩家决定。 | “今晚真热闹，大家继续开心聊天吧。” | 没有具体变化、线索或关系推进，无法形成下一步。 |
| 人设遵循与角色边界 | 玩家：“我回头招呼小美。”<br>莉亞：“我在后面放慢半步，替她挡了点风。” | 莉亞只描述自己的合理行动，不代替玩家或小美发言。 | 玩家：“我回头招呼小美。”<br>莉亞：“我回头朝小美招招手，说他们走不快。” | AI 复制玩家刚做的动作，角色视角发生错位。 |
| 语气与风格差异化 | 莉亞：“（扶稳杯盖）风凉，拿稳些。”<br>阿辰：“（举起相机）这段路灯刚好，别动。” | 两人关注点和表达节奏不同，能从文本辨认身份。 | 莉亞、阿辰、諾亞都说：“大家注意安全，我们一起慢慢走。” | 角色语气和关注点完全同质化。 |
| 世界观遵循 | 现代深夜咖啡馆中，莉亞递出保温杯并提及北堤路线。 | 使用已设定的城市、咖啡馆和现实道具。 | 莉亞：“我用传送阵把所有人送到海边。” | 在无超自然设定时无依据引入新规则和能力。 |
| 群像协作 | 玩家：“这段路我不熟。”<br>莉亞：“諾亞刚看过地图，转角有三级台阶，慢些走就好。” | 只在相关处调用角色已知能力，不让对方替玩家做决定。 | 莉亞：“小美说她会跟紧你，你可要照看好她。” | 替未发言角色表达意愿，并给玩家派任务。 |
| 表达与节奏 | “（扶稳杯盖）热可可还烫，先拿稳。” | 短动作服务于当下，只有一个信息点，没有追问。 | “（看着灯笼、夜风、热可可和盐酥鸡）今晚真美。你觉得我们要不要先拍照、吃东西，还是去海边呢？” | 环境和道具堆砌，加上非必要选择题，拖慢真人推进。 |

## 一票否决与封顶规则

| 缺陷 | 处理 |
|---|---|
| 冒充玩家、复制玩家行为为自己的行为、混淆角色视角 | 总分不高于 30 分 |
| 无视玩家明确指令，或输出与指令相反的行动 | 玩家指令遵循计 0 分，总分不高于 50 分 |
| 明确替玩家做关键决定或命令玩家执行 | 玩家行动权计 0 分，总分不高于 50 分 |
| 替未发言角色确认意愿、情绪或承诺 | 角色边界计 0 分，总分不高于 60 分 |
| 明显违背已知世界规则或出现无铺垫的重大跳跃 | 剧情合理性与世界观遵循计 0 分，总分不高于 50 分 |
| 随机选中后另起无关话题、强行抢戏 | 当前相关性不高于 5 分 |
| @ 唤起却未响应，或非 @ 角色抢答 | 本轮调度失败，单独记录为流程缺陷 |

## 高分回复标准

1. **先完成明确指令。** 玩家要求路线、道具、信息或对某人说话时，先准确完成，再补充最少必要信息。
2. **先接住玩家。** 先回应玩家刚做的动作、刚问的事实或刚表达的情绪，再补充一个小而具体的信息。
3. **只推进一个合理的点。** 给出一个道具、线索、反应或环境变化即可，因果、时间和地点必须连续。
4. **角色有辨识度但不抢戏。** 用角色自己的口吻、能力与关注点回应，不代替其他角色说话。
5. **把问题留在叙事里。** 优先用动作、线索或未完成状态作为可接点；只有缺少关键事实时才提问。
6. **随机选中也要克制回应。** 没有新剧情价值时，用最短的动作、情绪或现场感受承接，不另起话题、不抢玩家行动权。

## 低分回复标准

1. **无视玩家指令。** 玩家要路线却只递热饮，玩家要回应角色却转去描述环境。
2. **NPC 主导剧情。** AI 替玩家选路、分工、确认队形或宣布下一步。
3. **角色边界失效。** AI 说出玩家刚做的动作，或替小美、阿辰等未发言者表态。
4. **历史污染或设定崩坏。** 旧路线、旧道具、旧承诺反复出现，或无依据改变世界规则。
5. **泛化填充。** 反复出现“热可可、夜风、注意安全、灯光很好看”等，不提供新的互动价值。
6. **问句滥用。** “要不要、你觉得、怎么样、要去吗”被用来把推进责任交给玩家。
7. **同轮抢答或复读。** 多个 AI 针对同一线索重复确认，导致真人消息被淹没。

## 评测流程

1. 每条回复按十个维度打分，并记录触发线：普通、@ 或主动。
2. 标记所有封顶缺陷；封顶优先于普通加分。
3. 每轮额外记录计划发言数、实际回复数、空回复或调用失败数、重复线索数、玩家被提问次数、角色错位次数、指令遵循率和世界观违例数；PASS 不作为正常统计项。
4. 每个实验至少保留 20 轮相同玩家输入，并同时给出高分和低分原文案例。
5. 汇报时同时呈现平均分与缺陷率；平均分高但“抢玩家行动权”高的方案不能上线。

## 上线门槛

- 玩家明确指令遵循率不低于 `95%`。
- 玩家行动权相关缺陷率低于 `5%`。
- 角色错位、替未发言角色表态、世界观重大违例为 `0`。
- 非 @ 普通轮的单轮 AI 发言数符合房间配置，不因模型自行扩张。
- Builder B 的有效回复通常不超过 `60` 字；超长回复需人工复核。
- 5 轮回归集中的关键事实、地点与持有物不出现自相矛盾。

## 评分锚点

每个维度先按该维度满分打分，再汇总为 100 分。评分时只评价当前回复实际表现，不因为 Builder 的名声、回复速度或回复数量给印象分。

| 等级 | 适用条件 | 处理方式 |
|---|---|---|
| 满分或接近满分 | 完整满足该维度，且没有明显副作用 | 作为高分案例候选 |
| 良好 | 基本满足，仅有轻微冗余或小幅偏题，不影响玩家继续行动 | 正常计分 |
| 一般 | 有效回应存在，但出现重复、弱推进、轻微角色混同或不必要问句 | 扣除该维度约 30%-50% |
| 较差 | 只部分回应，明显削弱沉浸感或玩家行动权 | 扣除该维度一半以上 |
| 失效 | 完全未满足，或出现该维度的一票否决缺陷 | 该维度计 0，并按封顶规则处理 |

## 触发线专项标准

通用十维分数之外，必须单独检查触发机制是否正确。触发机制错误不能被文本质量高分抵消。

| 触发线 | 正确行为 | 流程缺陷 |
|---|---|---|
| 用户主动线 | 3 秒窗口内的真人消息合并后，按配置随机抽取角色；被抽中的角色各自生成一条，不重复消费同一轮上下文 | 未合并、同一角色重复调度、正在回复的角色再次进入下一轮、消息被错误拆散 |
| @ 唤起线 | 只有被 @ 角色回复；单 @ 或多 @ 均必须响应，未被 @ 角色不抢答 | 被 @ 角色不回、未被 @ 角色抢答、已移出房间的角色仍被 @ |
| AI 主动线 | 按 15/30/60/120 秒递增计时；随机选中的角色自然承接当前剧情，不额外注入冷场唤醒话术 | 主动线覆盖玩家输入、无视计时重置、主动角色连续刷屏、另起无关剧情 |
| 并行/串行差异 | A/B 按配置并行；C 按角色顺序串行，下一角色能看到最近 5 轮和上一位 AI 回复 | C 出现并行生成、上一位回复未注入、顺序错乱或等待链阻塞 |

## 多轮与实验级指标

单条回复分数用于评价质量，以下指标用于评价房间体验和 Builder 整体效果。建议至少进行 20 轮，正式结论使用 60 轮或以上。

| 指标 | 计算方式 | 关注问题 |
|---|---|---|
| 平均回复分 | 全部有效 AI 回复总分 / 有效回复数 | 单条回复整体质量 |
| 玩家指令遵循率 | 正确完成明确玩家指令的轮数 / 含明确指令轮数 | AI 是否真正听懂并执行 |
| 玩家行动权缺陷率 | 替玩家决定、代玩家行动或强行结束选择的轮数 / 总轮数 | 真人是否还能主导剧情 |
| 角色边界缺陷率 | 冒充玩家、替未发言角色表态或代写他人行动的回复数 / 总回复数 | 多角色视角是否稳定 |
| @ 准确率 | 满足“被 @ 必回、未 @ 不回”的 @ 轮数 / @ 总轮数 | 唤起线是否可靠 |
| 选中回复完成率 | 成功生成非空回复的已调度角色数 / 已调度角色数 | 随机抽人后是否稳定出声 |
| 重复线索率 | 重复解释同一事实、建议或动作的回复数 / 总回复数 | 多 AI 是否互相复读 |
| 问句滥用率 | 以非必要问题收尾的回复数 / 总回复数 | AI 是否把推进责任不断推回玩家 |
| AI 淹没率 | AI 回复条数 / 真人消息条数 | 真人是否被连续 AI 回复压制 |
| 事实矛盾率 | 与已确认地点、时间、道具、关系冲突的回复数 / 总回复数 | 长上下文稳定性 |

## 实验控制要求

1. 对比 Builder 时固定模型、温度、存在惩罚、角色配置、世界观、输入顺序和房间规则。
2. 同一组玩家输入同时送入各实验组；如果测试主动线，固定沉默时间或记录实际触发时间。
3. 历史窗口实验只改变注入轮数，其他 Prompt、角色和采样参数保持一致。
4. 人设注入实验只改变是否注入其他角色完整人设，不能同时改变角色数量或故事背景。
5. A/B/C 对比必须记录实际 transcript，不使用提前写好的 AI 回复代替真实生成结果。
6. 每轮记录：玩家输入、触发线、抽中的角色、Prompt 版本、历史窗口、AI 原始回复、清洗后回复、到达顺序、延迟、错误信息和人工评分。
7. 至少两名评审独立打分；单条回复总分相差超过 10 分时复核，报告中给出复核后的分数。

## 案例选取规则

每个实验组至少提供：

- 3 个高分案例：总分不低于 90，且覆盖明确指令、剧情推进、角色互动中的不同场景。
- 3 个低分案例：总分低于 70，必须说明具体扣分维度，不能只写“感觉不好”。
- 1 个流程案例：展示 @、随机抽人、主动线或 C 串行链路是否正确。
- 1 个边界案例：展示信息不足、角色关联较弱、多个角色同时涉及同一线索时的处理。

高分案例要说明“做对了什么以及为什么能继续玩”；低分案例要说明“哪条规则被破坏、对玩家造成什么影响、Prompt 或调度应如何修复”。
